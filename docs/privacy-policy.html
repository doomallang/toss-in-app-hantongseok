개인정보 처리방침

시행일: 2026년 5월 13일  |  최종 수정: 2026년 5월 13일

한통속은 이용자의 개인정보를 수집·저장·전송하지 않습니다.
게임 기록은 기기 내부(로컬 저장소)에만 저장되며, 외부 서버로 전송되지 않습니다.

1. 개인정보 수집 여부

한통속 앱은 회원가입, 로그인, 이름·이메일·전화번호 등 어떠한 개인정보도 수집하지 않습니다.

2. 기기 내 저장 데이터

앱은 아래 정보를 오직 사용자의 기기(로컬 저장소)에만 저장합니다.

  • 플레이 진행 상태 (현재 퍼즐, 선택 단어 등)
  • 게임 통계 (총 플레이 수, 연속 달성 횟수 등)
  • 설정 값 (색약 모드 등)
  • 퍼즐 데이터 캐시

이 데이터는 외부로 전송되지 않으며, 앱 삭제 시 함께 삭제됩니다.

3. 광고 (Google AdMob)

한통속은 Google AdMob을 통해 배너 광고를 제공합니다. AdMob은 광고 최적화를 위해 아래 정보를 수집할 수 있습니다.

  • 광고 ID (Android 광고 식별자)
  • 기기 유형 및 운영체제 버전
  • 앱 사용 이벤트 (광고 노출, 클릭)
  • 대략적인 위치 정보 (IP 기반)

Google의 개인정보 처리방침: policies.google.com/privacy

AdMob 데이터 사용 정책: AdMob 정책 보기

기기 설정에서 '광고 추적 제한' 또는 '광고 ID 재설정'을 통해 개인 맞춤 광고를 제한할 수 있습니다.

4. 제3자 데이터 공유

한통속은 이용자의 데이터를 제3자에게 판매하거나 공유하지 않습니다. AdMob을 제외한 외부 분석 도구나 추적 SDK는 사용하지 않습니다.

5. 아동 개인정보 보호

한통속은 만 14세 미만 아동을 대상으로 개인정보를 수집하지 않습니다. 본 앱은 연령 제한 없이 이용할 수 있으나, 광고 표시와 관련하여 Google AdMob의 아동 정책을 준수합니다.

6. 개인정보 처리방침 변경

본 방침이 변경될 경우 이 페이지를 통해 고지합니다. 중요한 변경 사항이 있을 경우 앱 업데이트 노트를 통해 별도 안내합니다.
